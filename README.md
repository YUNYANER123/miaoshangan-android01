# 喵上岸 · 28考研（2027）移动学习工作台

「喵上岸」是一个面向 **28考研（2027 年考研）** 同学的移动端学习管理工具：复习书目管理、每日学习时长 / 打卡追踪、阶段进度，以及可选的 **AI 生成**（帮你扩充题库、梳理知识点）。

它原本是一个网页应用（PWA）。本仓库把它打包成**可安装的安卓 APK**，方便直接发给同学装到手机上，像原生 App 一样用。

- 网页版（GitHub Pages）：`https://YUNYANER123.github.io/kaoyan28/`

---

## 功能一览

- 📚 **书目管理**：英语 / 数学 / 专业课书目分类记录，可增删。
- ⏱️ **学习追踪**：记录每天各科投入时长，阶段进度一目了然。
- 🙈 **阶段隐藏**：临近考试可隐藏某些阶段，聚焦当前。
- 🤖 **AI 生成**：基于你的进度让 AI 扩充题库、生成复习建议（需配置代理，见下）。

---

## 安装到手机

### 方式一：安卓 APK（最适合发给同学）
1. 在本仓库 **Releases**（或 Actions 构建产物的 Artifacts）下载 `miao-app-debug.apk`。
2. 传到手机并点击安装；首次需允许「未知来源应用」。
3. 装好即开即用。

> APK 由 GitHub Actions 自动构建，无需你本机装 Android Studio。

### 方式二：网页版当 App 用
手机浏览器打开 `https://YUNYANER123.github.io/kaoyan28/`，点菜单「添加到主屏幕」，即可从桌面图标像 App 一样启动。

---

## 高级：自己部署 AI 代理（可选）

不想用共享代理、或想用自己 DeepSeek 额度，可自行部署，详见 [`ai-proxy/README.md`](ai-proxy/README.md)：
1. 注册 DeepSeek 拿到 API Key；
2. 在 Cloudflare 建 Worker，粘贴 `ai-proxy/worker.js`；
3. 配置 `DEEPSEEK_API_KEY`，记下 `*.workers.dev` 地址；
4. 在 App 设置里把代理地址换成你自己的。

---

## 安全说明

- 共享代理的 Key 只存在于作者的 Cloudflare Worker 服务端，**不会进安装包、也无法从客户端取得**。
- 代理对来源不做强限制（便于大家直接用），但它只转发到作者自己的 DeepSeek 账户；想更严格可自行部署并加口令校验。
- App 本身不收集、不上传任何学习数据。

---

## 与网页版的关系

两个仓库共用同一套网页代码：本仓库构建时从 `kaoyan28` 拉取最新资源，因此网页版更新后重新跑一次 Actions 即可得到最新 APK。
